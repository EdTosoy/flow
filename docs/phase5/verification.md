8. **Date/time semantics.** Booked time mandatory canonical UTC milliseconds; source occurrence optional independent UTC timestamp; value date optional validated YYYY-MM-DD calendar date. Stock effective time comes only from supplied period endpoints or running balance's booked time; otherwise null.
9. **Balance-observation model.** Signed Money stocks labeled OPENING/CLOSING/RUNNING with account scope/currency, source interpretation and optional effective time. Running-balance sequence arithmetic and standalone balance feeds are deferred.
10. **Internal-control model.** Frozen as-of statement evaluations pin policy and input identities with typed selected-entry links. Opening + credits − debits is exact NUMERIC/bigint; reported closing stays independent. Full calculation is null when supported complete membership is unproven. Deterministic sorted controls cover closing mismatch, count/reference/sequence gaps, duplicate lines/references, cross-currency, reversed periods/ranges, out-of-period bookings, ambiguous entries/reports, pending selection, conflicting association and unverified identity. Arithmetic PASS/FAIL/UNVERIFIED is distinct from completeness. Malformed money/direction/time remains explicit failed bank-version normalization evidence.
11. **Completeness semantics.** UNKNOWN without independent count/list/sequence assertion; PROVEN_INCOMPLETE on failed supplied coverage; PROVEN_COMPLETE only when supplied scoped controls agree. 12. **Correction/revision behavior.** Changed source bytes/tokens create new immutable normalized and bank interpretations. Prior entries/memberships/stocks/control calculations remain intact.
